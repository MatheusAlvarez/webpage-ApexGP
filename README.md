## 💻 Sobre o projeto

**ApexGP** é um projeto fictício focado em uma empresa moderna que gerencia uma pista de kart de alto nível. O objetivo da aplicação é oferecer uma experiência imersiva e responsiva na web para os apaixonados por automobilismo e velocidade.

Este projeto foi desenvolvido com um propósito especial: **fins didáticos**. Ele foi construído durante o curso que leciono, onde o principal objetivo é ensinar na prática como criar páginas web modernas e interativas, com um grande foco no uso do **Google Antigravity** para acelerar o desenvolvimento com Inteligência Artificial, melhorando a produtividade na estruturação e estilização.

---

## ⚙️ Funcionalidades

- [x] Interface moderna e imersiva baseada no mundo do automobilismo.
- [x] Estruturação e desenvolvimento guiados utilizando o **Google Antigravity**.
- [x] Páginas responsivas, adaptando-se a celulares, tablets e desktops.
- [x] Navegação rápida e fluida desenvolvida com React e Vite.

## 🚀 Como executar o projeto

### Pré-requisitos

Antes de começar, você vai precisar ter instalado em sua máquina as seguintes ferramentas:
[Git](https://git-scm.com), [Node.js](https://nodejs.org/en/). 
Além disso, é bom ter um editor para trabalhar com o código como [VSCode](https://code.visualstudio.com/).

### Passo a Passo

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/MatheusAlvarez/webpage-ApexGP.git
   ```

2. **Acesse a pasta do projeto:**
   ```bash
   cd webpage-ApexGP
   ```

3. **Instale as dependências:**
   ```bash
   npm install
   ```

4. **Execute a aplicação em ambiente de desenvolvimento:**
   ```bash
   npm run dev
   ```

5. O servidor iniciará localmente. Acesse a URL indicada no terminal (geralmente `http://localhost:5173/`).

## 🛠 Tecnologias

As seguintes ferramentas foram usadas na construção do projeto:

- **[React](https://reactjs.org/)**: Biblioteca JavaScript para criar interfaces de usuário.
- **[Vite](https://vitejs.dev/)**: Ferramenta de build de frontend extremamente rápida.
- **Google Antigravity**: Utilizado ativamente no fluxo de desenvolvimento como assistente de IA, acelerando a criação das estruturas, componentes e lógicas.
- **CSS3 / HTML5**: Para estilização e marcação semântica avançada.

## 💪 Como contribuir para o projeto

Sendo um projeto didático, contribuições são super bem-vindas para melhorar a base de código ou adicionar novos recursos que possam servir de exemplo nas aulas!

1. Faça um **fork** do projeto.
2. Crie uma nova branch com as suas alterações: `git checkout -b minha-nova-feature`
3. Salve as alterações e crie uma mensagem de commit contando o que você fez: `git commit -m "feat: adicionando nova funcionalidade"`
4. Envie as suas alterações: `git push origin minha-nova-feature`
5. Abra um **Pull Request**.
